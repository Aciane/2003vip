# FBX粒子化交互装置艺术 - Web版本

## 🎨 项目概述

本项目使用 **Three.js + MediaPipe** 实现了一个交互式装置艺术：
- 将FBX模型（shao.fbx）转化为粒子系统
- 通过摄像头识别人物距离
- 根据距离动态改变粒子状态（近了就扩散/坍缩，远了就聚集）
- 粒子系统始终面向摄像头

## 📁 文件结构

```
letstalking/
├── index.html          # 主程序文件（所有代码都在这里）
├── run.sh              # 启动本地服务器的脚本
├── shao/
│   ├── shao.fbx        # FBX模型文件
│   └── shao.fbm/       # 纹理贴图
└── WEB_README.md       # 本说明文件
```

## 📋 使用说明

1. **打开页面后**，浏览器会请求摄像头权限，请点击"允许"
2. **选择摄像头**：如果电脑有多个摄像头，可以使用左下角的下拉菜单选择
3. **交互方式**：
   - **远离摄像头**：粒子紧密聚集，形成清晰的轮廓，颜色偏冷（蓝/青色）
   - **靠近摄像头**：粒子逐渐扩散，颜色变暖（橙/红色）
   - **非常靠近**：粒子大量扩散，产生"坍缩"效果

## ⚠️ 注意事项

### 1. 必须使用本地服务器
由于浏览器的安全策略，直接双击index.html打开可能无法加载FBX模型和纹理。请务必使用本地服务器（run.sh脚本）。

### 2. 浏览器兼容性
推荐使用以下浏览器：
- Chrome（推荐）
- Edge
- Firefox

### 3. 摄像头权限
首次打开时需要允许摄像头访问。

### 4. 光线要求
请确保环境光线充足，以便MediaPipe能准确检测人体姿态。

## 🎮 功能特性

| 功能 | 说明 |
|-----|------|
| 粒子化效果 | 将30,000个粒子组成模型轮廓 |
| 距离检测 | 基于MediaPipe姿态检测估算距离 |
| 粒子扩散 | 距离越近，粒子越扩散 |
| 颜色变化 | 冷色调(远) → 暖色调(近) |
| 朝向控制 | 粒子系统始终面向摄像头 |
| 实时UI | 显示距离、粒子数、FPS等信息 |

## 🔧 故障排除

### 问题1：模型加载失败
- 检查控制台是否有错误信息
- 确保使用本地服务器运行
- 检查FBX文件路径是否正确

### 问题2：摄像头无法打开
- 检查浏览器权限设置
- 尝试刷新页面
- 检查是否有其他应用占用摄像头

### 问题3：距离检测不准确
- 确保全身在画面中
- 保持适当距离（0.5-3米）
- 调整站立位置

### 问题4：粒子效果不明显
- 这是正常的，距离变化需要几秒钟传播
- 观察左上角的状态面板确认距离值在变化
