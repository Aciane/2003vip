# 🎨 TouchDesigner FBX 粒子化交互装置艺术

## 项目概述

本项目创建了一个基于 TouchDesigner 的交互式装置艺术，允许用户：
1. 将 FBX 模型（shao.fbx）转化为粒子系统
2. 通过摄像头识别人物距离
3. 根据距离动态改变粒子状态
4. 让模型始终朝向摄像头前的人物

## 🚀 快速开始

### 步骤 1: 安装依赖

```bash
# 安装 OpenCV (用于距离检测)
pip install opencv-python numpy
```

### 步骤 2: 在 TouchDesigner 中创建项目

1. 打开 TouchDesigner
2. 创建一个新的 `.toe` 项目文件

#### 2.1 导入 FBX 模型

- 在 TouchDesigner 中添加一个 **FBX Import** 组件
- 设置文件路径为 `shao/shao.fbx`
- 确保纹理正确加载

#### 2.2 粒子化处理

添加以下节点链：
```
FBX Import → Particle SOP → Point Render → Composite → Out
```

**Particle SOP 参数设置：**
- **Max Points**: 20,000
- **Life**: 10.0
- **Source**: 从 FBX 导入的几何体

#### 2.3 摄像头设置

- 添加 **Video Device In** TOP
- 选择你的摄像头（MacBook 内置或外接 USB）
- 分辨率建议：640x480 或 1280x720

#### 2.4 人物检测和距离估算

**方案 A: 使用 Blob Tracking（推荐）**

1. 添加 **Blob Track** CHOP
2. 连接到 Video Device In
3. 获取人物区域的面积
4. 使用面积计算距离

**方案 B: 使用 Python + OpenCV**

1. 创建一个 **Python DAT**
2. 导入 `distance_detector.py` 模块
3. 在 onFrame() 回调中调用检测函数

#### 2.5 粒子状态控制

根据距离值控制粒子：

| 距离状态 | 粒子效果 | 参数调整 |
|---------|---------|---------|
| **很近** (0.7-1.0) | 粒子扩散、闪烁、彩色 | 增加 dispersion, 明亮颜色 |
| **中等** (0.3-0.7) | 稳定形态 | 正常参数 |
| **很远** (0.0-0.3) | 粒子紧密、变暗 | 减小 dispersion, 暗淡颜色 |

#### 2.6 模型朝向控制

- 添加 **Look At** CHOP
- 设置目标为摄像头位置 (0, 0, 0)
- 使用 **Lag CHOP** 平滑过渡

## 🎭 预期效果

### 交互行为

1. **静止/远离**: 粒子紧密聚集，形成清晰的轮廓，像一个沉静的人物剪影
2. **靠近**: 粒子逐渐散开，像星尘一样飘动，颜色变暖（黄/橙）
3. **非常靠近**: 粒子大量扩散，产生"爆炸"效果，仿佛人物在粒子化分解
4. **模型始终面向**: 无论人物在哪个位置，粒子化的模型都会"注视"着人物

### 视觉风格

- 粒子颜色：冷色调（远离）→ 暖色调（靠近）
- 粒子大小：根据距离动态变化
- 粒子运动：基于噪声的有机运动
- 光影效果：添加点光源增强立体感

## ⚠️ 注意事项

### 1. 摄像头选择
- MacBook Pro 内置摄像头通常为 FaceTime HD
- 外接 USB 摄像头可能需要安装驱动

### 2. 距离检测精度
- 普通 RGB 摄像头无法直接获取深度信息
- 基于面积的估算方法受以下因素影响：
  - 人物体型差异
  - 衣服颜色（影响背景减除）
  - 光线条件
  - 背景复杂度

### 3. 性能优化
- 粒子数量建议：10,000-50,000
- 使用 GPU 渲染
- 避免在每帧进行大量计算

### 4. 校准
- 实际使用时需要根据环境调整：
  - 面积阈值
  - 平滑系数
  - 距离映射参数

## 🔍 故障排除

### 问题 1: FBX 模型无法加载
- 检查文件路径是否正确
- 确保 FBX 版本兼容（建议 FBX 2016+）

### 问题 2: 摄像头无法打开
- 检查摄像头权限（系统偏好设置 → 安全性与隐私）
- 尝试使用其他摄像头索引

###问题 3: 人物检测不准确
- 调整背景减除参数
- 增加照明强度
- 减少背景中的移动物体

### 问题 4: 粒子效果不明显
- 检查粒子 SOP 配置
- 调整粒子大小和散布参数
