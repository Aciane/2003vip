〇.五、三层架构：读懂二十七系的元框架

为什么需要这一层
二十七系不是同一平面上的二十七个工具。它们在本体论、认识论、应用域三个层级上各有位置。跨层调用而不声明兼容逻辑，是理论误用的主要来源。

Level 1 · 第一哲学与底层本体论（五种本体论承诺）

回答：世界的基本构成是什么？意义的最终起源在哪里？

编号本体论类型代表理论系核心主张
L1-A主体感知本体论现象学 / 4E 认知 / 解释学肉身感知的意向性是意义的绝对起点——但 L1-A 内部三分：胡塞尔（先验自我构成，保留先验主体）/ 海德格尔（此在在世，先验主体被解体）/ 梅洛-庞蒂（活的身体超越主客，无先验主体）。「先验主体不可消除」仅属胡塞尔，不代表 L1-A 整体。
L1-B结构差异本体论符号学（索绪尔系）/ 叙事学（经典期）/ 结构主义意义只存在于形式化的系统差异中，无预设主体实体
L1-C内在性流变本体论德勒兹的空间理论主义 / 情动理论废除先验主体，物质与强度的差异化生成是唯一实在；内在性平面
L1-D对象撤退本体论OOO（哈曼为核心）客体独立于一切感知或关系，具有不可穷尽的撤退内核；关联主义是哲学的囚笼
L1-E社会物质实践本体论历史唯物主义（马克思—列斐伏尔—阿尔都塞）生产方式与社会关系是意义和文化的物质基底；意识是上层建筑；实践先于理论
⚡ 基特勒的 L1 级理论宣称——媒介装置本体论（暂列 L1-G，待确认）
基特勒的核心命题"媒介决定我们的处境"（Medien bestimmen unsere Lage）是对海德格尔基础存在论的直接物质化改写：
- 考研日记/啊 艺术概论/海德格尔：此在在世展开，存在先于存在者 → L1-A 的根基
- 基特勒：媒介装置在历史上决定何物可被感知/表达/记忆——人类感知主体是话语网络的功能性产物，而非起点

这不是 L2 方法论（不只是"分析媒介如何影响社会"），而是 L1 级别的本体论宣称：媒介装置是存在的技术先天条件（technical a priori），优先于任何感知主体（L1-A）或差异系统（L1-B）。

| 维度 | 内容 |
|---|---|
| 与 L1-A 的关系 | 直接取代L1-A：媒介不是被人类主体使用的工具，人类是被媒介技术a priori所生产的效果 |
| 与 L1-C 的关系 | 有接近（物质性流动），但基特勒的媒介是历史性离散的技术系统，不是德勒兹的空间理论式的连续内在性平面 |
| L1 地位建议 | 暂记为 L1-G 媒介装置本体论，待进一步哲学确认。在坐标系中不应低于 L1，不得仅归 L2 或 L3-γ。|

→ 将基特勒放在 L2 或 L3-γ 是对其理论野心的系统性压制。
⚡ L1-D 内部阵营分裂：哈曼 ≠ 梅亚苏
将 OOO 与思辨实在论合并为 L1-D 是严重的范畴误植。两者共享"反关联主义"出发点，但走向截然相反：

| 维度 | 哈曼（OOO）| 梅亚苏（思辨唯物主义）|
|---|---|---|
| 核心主张 | 客体永远撤退，不可被任何关系穷尽 | 现实是绝对偶然的，数学可以直接触及思维无关的实在 |
| 对物自体 | 物自体永远撤退（保留康德的隐藏维度）| 明确拒绝物自体概念，反对任何"隐藏内核" |
| 对数学 | 美学比数学更接近对象 | 数学是通向绝对的唯一途径（先祖性陈述的可知性）|
| 认识论后果 | 知识永远是间接的、偶发的美学接触 | 数学化的实在可以被彻底认识 |

→ L1-D 仅适用于哈曼的 OOO。梅亚苏的思辨唯物主义是独立的本体论位置（待建）。
⚡ 马诺维奇≠AI潜在空间——历史错位修正
将马诺维奇与 AI 扩散模型并置于同一个"L1-F 概率本体论"是历史性错位：

| 维度 | 马诺维奇（2001）| AI 扩散模型（2020s）|
|---|---|---|
| 逻辑机制 | 从有限离散选项集合中组合/选择（范式轴 × 组合轴的数字化）| 在连续高维概率分布（潜在空间）中降噪采样 |
| 底层哲学 | 索绪尔范式轴/组合轴的计算机界面变体 → L1-B 结构差异本体论的延伸 | 统计物理学 + 多维拓扑论：存在=概率分布，实例=采样事件 |
| 对 L1-B 的态度 | 在 L1-B 框架内扩展 | 根本不是差异系统——没有固定词汇表，分布随训练数据连续变化 |

→ 马诺维奇应回归 L1-B 的扩展注释，不构成独立的 L1 本体论挑战。

真正的 L1-F 候选：AI 概率拓扑本体论（Probabilistic-Topological Ontology）
- 现实的基本形态 = 高维连续概率分布（非离散、非二元对立、非固定词汇表）
- 任何"存在物"= 从潜在流形（manifold）的随机采样实例，无原本，只有分布
- 时间 = 降噪过程（从高熵随机噪声收敛为低熵有序影像）→ 这是一种新的时间/生成本体论
- 这不是德勒兹的空间理论式的连续流变（L1-C）：扩散模型的生成是从固定训练分布中采样，不是无边界的差异化生成
- 这不是结构差异（L1-B）：分布空间中不存在离散的对立符号单元

尚无与此对应的成熟哲学体系，但量子场论本体论（Barad的 intra-action 物理哲学）、信息本体论（Wheeler "It from Bit"）、以及当前 AI 哲学研究有接近的论述。L1-F 仅指向 AI 生成逻辑的潜在哲学基底，与马诺维奇脱钩。

Level 2 · 认识论与方法论路径（四种策略）

回答：我们如何获取知识？论证逻辑的运作方式是什么？

方法论类型代表理论系操作特征
L2-α 现象学还原现象学 / 解释学 / 美学（Böhme线）悬置预设，回归"事物本身"的直接显现与理解
L2-β 谱系学 / 考古学媒介考古学 / 福柯系装置理论 / 生命政治拒绝目的论，挖掘话语形成的历史断裂与偶然性

⚡ L3-β2：巴特勒表演性归属的认识论矛盾
巴特勒的性别表演理论受德里达解构主义（引用性/iterability）和福柯话语分析深刻影响，是后结构主义产物：
- 她拆解的正是 L1-B 所依赖的"稳定的二元差异系统"（sex/gender 二元）
- 引用性（citationality）≠ 结构中的差异位置——前者允许偏移和改写，后者是封闭系统

因此 L3-β2 里的巴特勒根植于 L1-C 而非 L1-B，与 β2 中的阿尔都塞（L1-B）处于认识论断裂线的两侧。
使用巴特勒时必须声明：你调用的是 L1-B 的"主体被结构位置决定"还是 L1-C 的"主体在引用行为中偏移生成"——这两种用法在分析逻辑上不可互换。
⚡ L3-γ 两项 L1 级警示
- 马诺维奇数据库逻辑：见 §〇.五 Level 1 注释——暂置 L3-γ 但含 L1 级潜在挑战（L1-F 待议）
- 尼克·兰德超迷信（Hyperstition）：时间循环（未来激活过去）是对线性因果律的直接重构，属第一哲学层面的时间本体论挑战。当前暂置 L3-γ 是出于保守性分类，但其破坏力处于 L1 级别，不宜用普通"应用域"眼光读 Land。
谢克纳 vs 巴特勒：同名"表演"，不同本体论根
- 谢克纳（表演研究 / Performance Studies）：现象学身体为基础，关注具身的现场空间实践——环境剧场、仪式、再现（restoration of behavior）→ 归 L3-α，根在 L1-A
- 巴特勒（表演性 / Performativity）：德里达引用性为基础，性别在话语的重复引用中偏移生成 → 归 L3-β2，根在 L1-C（后结构主义），不是 L1-B
- 两者共享"performance"词根，本体论根基和分析逻辑不可混用
L3-α 空间理论的 L1-E 声明
列斐伏尔《空间的生产》(1974) 严格依赖历史唯物主义基底：空间不是中性容器，而是被特定生产方式与社会关系生产出来的。不声明 L1-E 基底而直接使用空间理论，会丢失其分析力的核心。
- L1-E（历史唯物主义）→ L2-β（谱系学/历史批判）→ L3-α（空间的社会生产分析）：这是列斐伏尔的完整路径
- 球域学（斯洛特戴克）则根在 L1-A（现象学共居）→ 两种"空间理论"不可混同调用
L3-α 美学的内部分裂
"美学"并非单一的 L1-A 应用域：
- Böhme 气氛美学 / 早期审美理论（康德—胡塞尔路线）：根在 L1-A 主体感知 ✓
- 阿多诺《美学理论》（否定辩证法）：根在批判理论 / L1-B/C 的否定辩证逻辑，对商品化和同一性的批判优先于感知还原
- 朗西埃"感性分配"：权力如何划定可见/可听/可言的边界——根在 L1-B/C 的政治拓扑学，是权力分析而非感知还原
→ 使用"美学"框架时必须声明你调用的是哪条根
强制性声明原则
当你写"后人类主义 AI 影像"时，必须先声明本体论基底：
- "德勒兹的空间理论式内在性流变"基础上的后人类（生成 / 差异化）→ 影像是强度流动
- "OOO 对象撤退"基础上的后人类（AI 作为不可穷尽的撤退对象）→ 影像有永远无法被把握的内核
- "Level 2 症状阅读"框架下的后人类（AI 作为意识形态装置）→ 影像再生产权力关系

三种后人类的分析结论截然不同。同理适用于"装置理论"：鲍德里的 apparatus（拉康系，结构差异本体论 + 症状阅读）与福柯的 dispositif（内在性 + 谱系学）不可互换。
认识论断裂：结构主义 → 后结构主义
符号学/叙事学（结构差异本体论，Level 1）与德勒兹的空间理论主义/情动理论/装置理论（内在性流变本体论）之间存在认识论上的根本断裂——后结构主义不是对结构主义的"修正"，而是对其基础的拆解。在同一分析里不说明兼容逻辑地并用两者，会产生逻辑矛盾。

1. 现象学（Phenomenology）[[电影现象学整体谱系-总地图]] [[薇薇安索布恰克电影身体研究知识谱系]]

血统：

胡塞尔《逻辑研究》(1900)《观念 I》(1913)："回到事物本身"，意向性，超验[[还原]]
    → 梅洛-庞蒂《感知现象学》(1945)：corps vécu（活的身体），身体图式，肉身性
    → [[海德格尔]]《存在与时间》(1927)：此在在世，工具性，存在论转向
    → 萨特《想象物》(1940)：意识的虚无化，影像的准现实性
    → 电影现象学两支：
        ├── 写实主义/本体论路线：[[巴赞]]（影像是被摄物的分身）→ 见 #4 解释学
        └── 身体路线：Sobchack《眼睛的调度》(1992), Laura Marks 触感视觉,
                       Jennifer Barker 触感观影, Carbone, 梅洛-庞蒂派

核心问题：意义如何在肉身感知中原初发生？身体不是意识的容器，而是意义的生产场所。

关键概念：

  • 意向性（intentionality）：意识总是"关于某物的意识"——没有空洞的意识
  • 活的身体（corps vécu）：梅洛-庞蒂：身体是知觉主体，不是客体
  • 身体图式（body schema）：身体对世界的无意识运动预期，习惯性延伸至工具
  • 间肉身性（intercorporeality）：身体与身体之间的共鸣感知结构
  • 电影的身体（film's body）：Sobchack：电影本身有意向结构，既是意向主体又是被感知客体
巴赞与现象学的关系（→ 详见 §一 · 4. 解释学本课精读）
巴赞的写实主义本体论与现象学有深刻亲缘（影像本体论 ≈ 影像现象学），但他走的是解释学—美学路径而非梅洛-庞蒂身体路径。在课程中，巴赞是解释学传统的代表人物。

与其他系的关系：

  • 是符号学、解释学、4E认知的理论基础母体之一
  • 梅洛-庞蒂被 Sobchack / Marks / Barker / Carbone 直接用于电影身体理论
  • 被符号学（索绪尔系）批判为"过于依赖先验主体"
  • 与情动理论有亲缘，但情动理论绕开了主体（→ 见 §九 情动理论）
⚡ L1-A 内部的本体论三分：不可混用
「现象学」在 L1-A 下掩盖了三种不兼容的本体论承诺：

| | 胡塞尔 | 海德格尔 | 梅洛-庞蒂 |
|--|--------|----------|-----------|
| 主体地位 | 先验自我（不可消除的构成中心） | 此在（无先验主体，总已在世） | 活的身体（前主体，超越主客） |
| 本体论姿态 | 拒绝教条本体论；从描述中建构形式/区域本体论 | 显性存在论（Sein的问题优先于一切） | 知觉本体论（肉，chiasme）；半显性 |
| 历史性 | 晚期才引入（生活世界）；主要是共时分析 | 核心（时间性是此在存在的意义） | 习惯/传统；身体历史沉淀 |
| 他者 | 同感推理（alter ego） | 共同此在（Mitsein） | 身体间可逆性，先于推理 |

调用现象学时必须声明是哪一支：Sobchack/Marks/Barker 走的是梅洛-庞蒂路径，不是胡塞尔先验意识路径；解释学（Gadamer/Ricoeur）走的是海德格尔路径。混用会产生「先验自我」与「具身主体」之间的逻辑矛盾。

→ 详见 现象学

2. [[符号学]]（Semiotics）

血统：

A · [[索绪尔]]系（Structuralist Semiology）：
    Saussure《普通语言学教程》(1916)：能指/所指，差异系统，语言符号任意性
        → 雅各布森（隐喻/转喻轴，语言六功能）
        → 巴特（早期）：神话学，图像修辞
        → 麦茨《电影表意泛论》(1968)：大共时组合段，电影是 langage
        → 麦茨《想象的能指》(1977)：精神分析转向
        → 帕索里尼"诗的电影"(1965)：现实符号论（边界人物，→见下）

B · 皮尔斯系（Semiotics / C.S. Peirce）：
    Peirce：图像/索引/象征（icon / index / symbol）
        → [[德勒兹]]借用并柏格森化（→ 见 #10 德勒兹主义）
        → Sobchack：摄影影像的索引性 + 现象学（跨系融合路径）

核心问题：意义由差异系统产生；没有差异就没有意义。电影能否被分析为一套可形式化的"语言"系统？

本课精读：

📖 克里斯蒂安·麦茨《电影表意泛论》(1968) "虚构故事片中的外延问题" - 核心命题：电影是 langage（语言实践/语言运用）而非 langue（封闭的词法系统）——电影没有词典 - 外延（dénotation）：叙事内容本身（"一辆自行车被偷了"） - 内涵（connotation）：叙事之上的风格/意识形态值（新现实主义 = 道德诚实的内涵） - 大共时组合段（grande syntagmatique）：对叙事电影"句法"的系统描述，8 种叙事段落类型： 自主镜头 / 平行组合段 / 括弧组合段 / 描述组合段 / 交替叙事段 / 场景 / 普通段落序列 / 插段序列 - 这是把索绪尔符号学系统**应用于电影叙事的奠基文本——同时也是后来被后结构主义整体拆解的靶子
📖 P.P. 帕索里尼"诗的电影"(1965) - 影像符号的特殊性：影像以现实对象本身为符号材料（物质索引），不是任意约定的——与索绪尔系根本分歧 - 散文电影 vs 诗的电影：散文电影透明叙事、隐藏摄影机；诗的电影暴露摄影机的在场（"摄影机意识"） - 自由间接主观性（soggettiva libera indiretta）：摄影机同时是角色视点和作者视点，不可分割（费里尼、安东尼奥尼、戈达尔） - 帕索里尼处于符号学与现象学的边界**：用语言学框架，但坚持影像的物质—现实索引维度 - 与麦茨的核心分歧：麦茨把影像纳入索绪尔差异系统；帕索里尼拒绝把影像符号还原为约定性差异
⚠️ 认识论断裂
麦茨所代表的索绪尔系符号学（L1-B 结构差异本体论）与德勒兹的空间理论/情动/后结构主义（L1-C）之间存在根本性断裂——后者不是对前者的修正，是对其基础的拆解。见 §〇.五

4. 解释学（Hermeneutics）

血统：

施莱尔马赫 → 狄尔泰（精神科学方法论）
    → [[海德格尔]]《存在与时间》：此在解释学，理解是存在方式而非方法
    → Gadamer《真理与方法》(1960)：效果历史，视域融合，游戏，文本自主性
    → Ricoeur《时间与叙事》三卷(1983-85)：叙事的时间性，三重模仿（mimesis I/II/III）
    → 电影解释学: Dudley Andrew, Robert Stam（互文性）, [[巴赞]]传统

本课精读：

📖 安德烈·巴赞《电影是什么？》— 第一至三周（文章 1、2、3） 巴赞处于解释学 + 写实主义美学 + 早期电影现象学的交汇点： 文章 1："摄影影像本体论"(1945) · 第一周 - 摄影的本体论功能：影像是被摄物的"分身（momie）"——将时间中的存在凝固 - 摄影 vs 绘画：绘画是诠释（主观），摄影通过物质因果（化学/光学）获得客观性；影像是被摄物的遗留物（empreinte） - 索引性（index）：巴赞的影像本体论与皮尔斯的索引符号概念高度契合（见 #2 符号学 B 系） - 反蒙太奇论：蒙太奇由导演强加意义；景深+长镜头尊重现实的多义性，保留观众的诠释自由 文章 2："电影语言的演进"(1950-55) · 第二周 - 电影史的双重轴：相信影像的导演（格里菲斯/爱森斯坦：蒙太奇派）vs 相信现实的导演（茂瑙/弗拉哈迪：写实派） - 1940s 转折（景深时代）：奥逊·威尔斯《公民凯恩》+ 意大利新现实主义 → 现实的多义性替代蒙太奇的意义单义性 - 景深不是风格选项，而是本体论选择：让观者在同一时空内自由"诠释"，而非被剪辑"告知" 文章 3："评《偷自行车的人》"(1949) · 第三周（与汤普森文章 4 并读） - 意大利新现实主义实践批评：非职业演员 / 实景拍摄 / 素材剧本 - 与汤普森的关键读法对比： - 巴赞（解释学—本体论路径）：这些选择尊重了现实的真实性 - 汤普森（形式主义路径）：这些选择本身就是一套可分析的形式策略 - 两种读法的张力 = 本课核心认识论问题：写实主义是本体承诺还是形式选择？

5. 叙事学（Narratology）

血统：

俄国形式主义（什克洛夫斯基"陌生化"，普罗普《故事形态学》1928）
    → 结构主义叙事学：Lévi-Strauss → Greimas（行动元模式/符号方阵）
        → Genette《叙事话语》(1972)：聚焦，语速，顺序，频率
    → 经典电影叙事学：Chatman《故事与话语》(1978), Bordwell《叙事电影》(1985)
    → 新形式主义：汤普森《打破玻璃盔甲》(1988)：形式主义 + 认知心理学
    → 后经典叙事学：向认知/现象学/跨媒介回归（Ryan, Herman, Stam）

本课精读：

📖 克里斯汀·汤普森《打破玻璃盔甲：新形式主义电影分析》(1988) — 第三、四周（文章 4、5） 新形式主义（Neoformalism）：俄国形式主义"陌生化"原则 + 认知心理学（图式/推断）+ 导演意图分析 文章 4："从形式的视角看现实主义"（《偷自行车的人》） · 第三周（与巴赞并读） - 核心反驳："现实主义"本身是一套形式体系，没有"透明"或"自然"的现实主义风格 - 意大利新现实主义的每个"现实"选择（非职演员/实景/线性叙事）都是可分析的形式策略 - 与巴赞的认识论张力：巴赞认为这些选择尊重现实（本体论论点）；汤普森认为它们与蒙太奇同样是"人工构造"（形式论点）——这组张力是导论周到第三周的核心对话 文章 5："参数形式的知觉挑战"（小津《晚春》） · 第四周 - 参数形式（parametric form）：形式元素（镜头长度、机位高度、空镜头/枕头镜头）以独立于叙事的规律自我变奏时，叙事功能退后，形式参数本身成为观看核心 - 小津的"枕头镜头（pillow shots）"不服务于叙事连贯性，是纯粹的形式参数——造成"认知陌生化" - 与德勒兹的空间理论"纯粹光学声音情境"有隐性共鸣：两者都在讨论超出叙事功能的影像时刻

与其他系的关系：

  • 是 L1-B 结构差异本体论最系统的电影应用（⚪ 经典期无身体论）
  • 经典叙事学 + 麦茨符号学共同构成 1960-80s 的电影理论"科学化"阶段
  • 被 Bordwell 认知主义接管；被现象学（Sobchack）指责为"无身体的叙事机器"
  • 新形式主义（汤普森）是叙事学的认知化当代发展，仍在 L1-B 框架内

6. 美学（Ästhetik / Aesthetics）

血统：

Baumgarten《美学》(1750, 首次命名) → 康德《判断力批判》(1790)
    → 黑格尔《美学》→ 尼采《悲剧的诞生》
    → [[克罗齐]]（表现主义美学）
    → 杜威《作为经验的艺术》(1934, 实用主义美学)
    → [[阿多诺]]《美学理论》(1970, 否定辩证法)
    → 当代: Böhme 气氛美学 / Rancière 感性分配 / 韦尔施后现代美学

核心问题：感性经验的自律性、审美判断的普遍性、艺术与生活的边界

⚡ 美学的内部 L1 分裂——这是一个高度异质的领域
将"美学"整体归入 L1-A（主体感知本体论）是过度同质化。美学谱系内部跨越多个 L1：

| 美学传统 | L1 基底 | 核心逻辑 |
|---|---|---|
| 康德审美判断 / 胡塞尔现象学美学 / Böhme 气氛美学 | L1-A 主体感知 | 感知主体的先验/身体结构是审美经验的起点 |
| 阿多诺《美学理论》（否定辩证法） | L1-B/C 否定辩证逻辑 | 艺术通过否定同一性（Identitätsdenken）来抵抗文化工业；根在批判理论而非感知还原 |
| 朗西埃"感性分配" | L1-B/C 政治拓扑学 | 谁有权可见/可听/可言的权力分配；是政治本体论问题，不是感知问题 |
| 尼采《悲剧的诞生》 | 早期 L1-C 前驱 | 艺术=生命力量的过剩表达；酒神 vs 太阳神是强度的对立，非主体感知的差异 |

→ 使用"美学框架"时必须先做 L1 声明：你的"美学"是感知还原式、否定辩证式还是政治分配式？

与其他系的关系：

  • 是现象学、符号学、解释学的共同母体之一——几乎所有理论系都从美学借概念又反美学
  • Baumgarten 的"感性学"原意就是"关于感知的学问"，与现象学天然亲缘
  • 康德"无利害的审美愉悦"被现象学（胡塞尔的悬置）借用，被情动理论批判
  • Böhme 气氛美学是美学最接近现象学身体理论的当代接口（本库已收多篇相关论文）
  • Rancière"感性分配"(partage du sensible)：美学与政治的交点，但 L1 根基是 L1-B/C，不是 L1-A——与文化研究对话而非与现象学对话

电影节点：

  • 早期电影美学（明斯特伯格、卡努杜、爱因汉姆）— 格式塔-美学路径
  • 阿多诺对"文化工业"的批判 → 与批判理论合流
  • Rancière《电影寓言》《影像的命运》— 感性分配在电影里的实践

7. 精神分析（Psychoanalysis）

血统：

弗洛伊德 → [[拉康]]（镜像阶段、象征/想象/实在三界）
    → 电影精神分析: Baudry / Metz / Mulvey / Heath / de Lauretis
    → 后[[拉康]]: Žižek（意识形态-幻象）/ Copjec / McGowan
    → 克里斯蒂娃（原初符号域 / abjection）

核心问题：无意识、欲望、凝视、认同如何在观影中运作

⚡ 拉康体系内部的 L1 断裂：符号界（早期）vs 实在界（晚期）
将精神分析整体锁定在 L1-B（结构差异本体论）是对晚期拉康的严重截断：

| 维度 | 早期拉康（符号界为主）| 晚期拉康（实在界/享乐）|
|---|---|---|
| 核心 | 符号秩序（大他者/能指链）是主体的结构性基础 | 实在界（The Real）：符号系统内部不可消除的创伤性剩余 |
| L1 归属 | L1-B 结构差异本体论 ✓ | 接近否定性本体论（L1-B 的内部死锁，或 L1-C 的极限形式）|
| 代表概念 | 镜像阶段、大他者、缝合、凝视（作为缺失位置）| object petit a（剩余享乐）、症状（sinthome）、享乐（Jouissance）|
| 电影分析后果 | 分析影像的符号秩序、意识形态缝合 | 分析影像中抵抗象征化的核心：创伤影像、断裂、不可还原的强度 |

Žižek 的位置：他的电影分析核心在晚期拉康——幻象（fantasy）是意识形态用来填补实在界裂口的机制。幻象的对象不是象征性差异，而是 object a（剩余/无法符号化之物）。

→ 对实在界/享乐有分析力的精神分析已越出 L1-B，进入一种独特的否定性本体论：现实的核心是一个不可象征化的裂口（hiatus），而非差异系统。处理影像中的创伤、断裂、非理性涌现时，须调用晚期拉康而非早期符号论拉康，两者不可混同。

关键概念（电影）：

  • 装置（apparatus）论（Baudry）：摄影机—放映机—银幕 构成"梦境装置"
  • 缝合（suture）（Oudart / Heath）：观众被剪辑—对话—凝视"缝进"文本
  • 凝视（gaze）（Mulvey）：男性凝视对女性身体的视觉控制
  • 幻象（fantasy）/ 实在界（Žižek）：意识形态通过幻象填补实在界裂口运作；电影核心是那个无法被叙事消化的剩余

本课精读：

📖 劳拉·穆尔维"视觉快感和叙事性电影"(1975) 精神分析（弗洛伊德/拉康）× 女性主义的奠基性交叉文本，Screen 杂志发表，1970s 电影理论的地震点。 论证结构： - 经典好莱坞叙事建立在窥淫快感（scopophilia）（弗洛伊德）+ 镜像认同（拉康）的双重机制上 - 叙事电影中的凝视结构是男性的（三重凝视：摄影机→银幕上的男性角色→观众，都预设男性观看位置） - 女性身体 = 奇观（spectacle）：女性在叙事中冻结故事流动，成为"被看"的对象（to-be-looked-at-ness） - 处理女性作为阉割威胁的两种机制：恋物（fetishism）（美化女性身体以否认差异）/ 偷窥-窥探（voyeurism/sadism）（惩罚、拯救或降低女性） 关键论点的坐标： - L1 基础：L1-B（拉康的结构差异本体论：主体通过符号秩序构成） - L2 方法：症状阅读（穿透银幕快感的表象，定位其中的欲望—权力结构） - L3 域：L3-β 权力/主体化维度（性别作为权力铭写的身体） 后续反驳与发展： - 玛丽·安·多纳（Mary Ann Doane）：女性观众的位置——过度认同（masochism）/ 扮装（masquerade） - E. Ann Kaplan：凝视不只是性别化的，也是种族化/阶级化的 - Sobchack 的现象学反驳：穆尔维的凝视理论预设了一个"无身体的观看主体"；现象学坚持观看者有肉身，观影快感是身体的而非仅仅是心理结构的

与其他系的关系：

  • 是 Sobchack 明确反拨的对象——她用身体现象学替代"无身体的凝视"
  • 与符号学高度融合（Metz 把拉康术语结构符号学化）
  • 被情动理论批判为"过于依赖表征和意义"，忽略前表征的强度
  • 被 4E 认知科学批判为不可证伪、脱离神经/身体基础
  • Žižek 路径则把精神分析与批判理论、德勒兹的空间理论嫁接，持续活跃

8. 批判理论（Critical Theory / [[法兰克福学派]]）

血统：

马克思 → 黑格尔左派
    ├── A线：[[法兰克福学派]] (霍克海默, [[阿多诺]], 马尔库塞, 本雅明)
    │       → 哈贝马斯（沟通理性）→ 霍耐特（承认理论）/ 弗雷泽
    └── B线：结构主义马克思主义
            阿尔都塞《意识形态与意识形态国家机器》(1970)
                → 询唤（interpellation）：主体不是自发的，而是被意识形态"呼唤"进存在
                → 这是 1970s《电影手册》Comolli/Narboni 意识形态电影批评的**直接理论引擎**
                → 葛兰西（霸权 hegemony）← 伯明翰文化研究的核心工具
                → 与[[拉康]]焊接：阿尔都塞询唤 + 拉康镜像阶段 → Baudry 装置论的哲学基础
阿尔都塞不是"旁支"
阿尔都塞的询唤理论是 1970 年代电影理论（装置论 / 意识形态批评）的轴心，直接生产了《电影手册》时期、Screen 杂志、以及后来的凝视理论的认识论基础。把他列为"旁支"是对这段历史的严重低估。

核心问题：文化（工业）如何再生产权力关系？启蒙如何转变为宰制？主体如何被意识形态询唤进入自己的位置？

关键概念（电影）：

  • 文化工业（Adorno/Horkheimer）：好莱坞是标准化的意识形态生产
  • 本雅明《机械复制时代的艺术作品》(1935)：灵韵（Aura）、震惊（Schock）、政治化的艺术
  • 询唤（interpellation）（Althusser）：电影通过识别机制把观众"呼唤"进意识形态主体位置——这是装置论的哲学根基
  • 意识形态批评：《Cahiers du cinéma》1970s Comolli/Narboni 分析电影如何再生产意识形态

与其他系的关系：

  • 阿尔都塞 × 拉康：询唤 + 镜像阶段 → 装置理论（#19）的哲学基础；是 A线与精神分析的关键焊接
  • 本雅明"触感性接受（tactile reception）"与现象学有隐性亲缘（他谈到身体如何习惯媒介）
  • 与文化研究（伯明翰学派）是母子关系（B线经葛兰西进入伯明翰）
  • 被情动理论批判为太依赖"意识形态批判"的认知框架，忽略身体-情感层

9. 情动理论（Affect Theory）

血统：

斯宾诺莎（affect = 能力的增减）
    → [[德勒兹]]-加塔利《千高原》(1980)：强度、生成、解辖域化
    → Brian Massumi《情动的释义》(2002)：情动先于情感
    → Sara Ahmed《情感的文化政治》(2004)：情动有方向性、有政治性
    → 西沃罗（Steven Shaviro）《后电影情动》(2010)：电影中的情动经济
    → 劳伦·贝朗特（Lauren Berlant）：残酷的乐观主义

核心问题：情动（affect）≠情感（emotion）：情动是前意识的强度，情感是主体化后的情绪。影像如何传递、调动情动？

关键区分：

  • 情动（affect）：身体的能力变化，前主体，不可表征
  • 情感（emotion）：情动被命名/主体化后的产物
  • 强度（intensity）：情动的计量单位

与其他系的关系：

  • 与现象学的亲缘：都关注身体、都承认前语言层——但现象学仍以主体为中心，情动理论绕开了主体
  • 马苏米批判现象学：phenomenology 仍保留"我感知"的主体结构；情动理论要的是"在主体构成之前的流动"
  • 与德勒兹的空间理论主义高度重叠（德勒兹借斯宾诺莎的 affect 概念）
  • 与新物质主义汇流（非人类的情动能量）
  • 电影里：Shaviro 把情动理论用于分析后电影（数字影像的情动经济）

10. [[德勒兹的空间理论]]主义（Deleuzianism）

德勒兹的空间理论在电影理论里足够独立成系，不宜简单归入现象学或情动理论。

血统：

柏格森（运动/时间/绵延）
    + 斯宾诺莎（内在性、情动）
    + 尼采（差异与重复）
    + 皮尔斯（符号的三元性）
    → [[德勒兹]]《差异与重复》(1968)《反俄狄浦斯》(1972，与加塔利合著)
    → [[德勒兹]]《电影 1：运动-影像》(1983)、《电影 2：时间-影像》(1985)
    → 当代: Rodowick / Flaxman / 姜宇辉（中文）

核心问题：影像本身如何思考？运动-影像（行动感知情感）与时间-影像（纯粹光学声音情境）如何区分？

关键概念：

  • 运动-影像 / 时间-影像
  • 情动-影像（affect-image）/ 知觉-影像 / 行动-影像
  • 块茎（rhizome）/ 生成（becoming）/ 内在性平面
  • 褶子（fold）/ 差异化重复

本课精读：

📖 吉尔·德勒兹的空间理论《时间-影像》(1985) — 第八周："时间的晶体"（第 8 章） 为什么这一章是《时间-影像》的核心： 前几章论证了二战后电影向时间-影像的转变（意大利新现实主义/法国新浪潮）；第 8 章给出了时间-影像最纯粹的形态：晶体-影像（crystal-image） 晶体-影像的结构： - 时间不是顺序流动的（过去→现在→未来），而是现在与它自己的过去同时并存 - 晶体-影像 = 现在与过去的不可辨别点（point d'indiscernabilité）：在影像中已经无法区分"正在发生的"与"刚刚过去的" - 四种晶体形态：完美晶体（镜）/ 破裂晶体（费里尼/雷诺阿） / 萌芽晶体 / 运动晶体（Ophüls 的摄影机运动） 关键例子（德勒兹的空间理论的文本分析）： - 雷诺阿《游戏规则》(1939)：现实与扮演的不可辨别性 → 破裂的晶体 - 费里尼《八又二分之一》(1963)：记忆/幻想/现在同时涌现 → 晶体的多层叠置 - 温特斯（Welles）《公民凯恩》(1941)：时间的非线性地层 与其他文本的关联（本课内部）： - 与巴赞的隐性对话：巴赞爱长镜头因为"尊重现实"；德勒兹的空间理论爱长镜头因为它生产了"时间的直接影像"——不同本体论，相似实践 - 与汤普森的张力：汤普森的参数形式分析（枕头镜头超出叙事）在德勒兹的空间理论这里有另一种解释：那些"超出叙事"的时刻正是纯粹光学声音情境（opsigne/sonsigne），是时间-影像的入口 坐标：L1-C（内在性流变本体论）；L2 = 内在性分析（不做"症状揭露"，而是描述影像的内在差异化生成）

与其他系的关系：

  • 与现象学：表面相似，内核对立。德勒兹的空间理论拒绝"主体—意识"的现象学框架，用"内在性"替代"意向性"
  • 与符号学：借用皮尔斯但柏格森化了——符号不是"代码关系"而是"影像的运动模式"
  • 与情动理论：高度重叠（马苏米直接来自德勒兹的空间理论）
  • 与系统论/控制论：通过"自组织"概念有隐性对话
  • 中文最主要的电影德勒兹的空间理论主义者：姜宇辉（本库已收多篇）

12. 媒介理论 / 传播学（Media Theory / Communication Studies）

血统：

    ↓（数字转向）

  • 问题：媒介如何塑造人的感知、主体性、历史？

(c) 数字/软件本体论（新媒体理论）：马诺维奇 → Fuller → Galloway

  • 问题：数字媒介的本体论特征是什么？算法如何组织文化逻辑？
  • 身体观：在可变数据库中被参数化的身体；AI 生成的"身体"是统计分布的实例
对 创作的直接意义
马诺维奇的数据库 vs 叙事对立，直接命中 AI 动画的本体论问题：你生成的每一帧不是"叙述"出来的，而是从潜在统计空间里"采样"出来的。这不是传统叙事媒介，而是数据库美学。Sobchack 的"电影身体"理论是否适用于数据库本体的影像，这是一个开放的研究问题。

  • 与现象学：麦克卢汉晚年自称"现象学家"，但更接近感知生态学；马诺维奇的数据库逻辑则与现象学的"身体—意向性"基本不兼容
  • 与技术哲学：基特勒直接对抗考研日记/啊 艺术概论/海德格尔技术哲学（"媒介决定人"反"人使用技术"）

  • 与系统论：香农信息论和维纳控制论同源

15. 4E 认知科学（Embodied / Embedded / Enacted / Extended Cognition）

4E：

  • Embodied（具身）：认知依赖身体的形态和感觉运动能力
  • Embedded（嵌入）：认知嵌入环境
  • Enacted（生成/行动）：认知是行动者与环境的共同创生
  • Extended（延伸）：认知系统延伸到工具和媒介中

与其他系的关系：

  • 是现象学的认知科学翻译，但更愿意接受神经科学证据
  • 与精神分析正面冲突：4E 认为精神分析的无意识理论无法被验证
  • 与技术哲学（Ihde 的后现象学）高度重叠
  • 与系统论亲缘：autopoiesis 是具身认知的生物学基础
  • 在电影：认知电影研究（Bordwell/Carroll/Plantinga）与现象学电影研究（Sobchack）之间的调解空间

16. 新物质主义（New Materialism）

血统：

斯宾诺莎（物质内在性，情动）
    → [[德勒兹]]-加塔利（块茎，生成，非有机生命）
    → 凯伦·巴拉德（Karen Barad）《与宇宙相遇》(2007)：intra-action, 物质-话语纠缠
    → 简·本尼特（Jane Bennett）《有活力的物质》(2010)：物质的活力（vital materialism）
    → 露西·伊里加雷 + 布拉伊多蒂（Rosi Braidotti）：后人类女性主义物质论

核心问题：物质不是被动的"被赋予意义的底质"——物质自己有能动性、有力量、有差异化生成能力。

关键概念：

  • intra-action（巴拉德）：不是"相互作用（interaction）"（两个已存在的实体），而是"纠缠中的相互构成"
  • vital materialism（本尼特）：电、食物、垃圾等物质聚集体的政治
  • 物质-话语纠缠：后结构主义话语论 × 量子物理学

与其他系的关系：

  • 批判符号学和话语分析"把一切化为语言"
  • 与现象学的差别：现象学仍以主体身体为中心，新物质主义去中心化，让非人类物质也参与
  • 与情动理论高度重叠（都继承斯宾诺莎-德勒兹的空间理论）
  • 与后人类主义互为补充：后人类提供政治框架，新物质主义提供本体论
  • 对 AI 动画的直接意义：AI 生成影像的"物质性"—— GPU、电力、数据流、像素聚合体——都有自己的能动性

17. 后人类主义（Posthumanism）

血统：

核心问题：启蒙人文主义的"人"（理性、自律、统一主体）已经结束。赛博格、AI、生物技术之后，什么是"我们"？

两个方向：

  • 与现象学：部分对话（Zahavi 的最低限度自我论 vs 后人类的去中心化主体）
  • AI 动画的创作身位：你正在操作的是一种后人类创作实践——作者、机器、影像三者共同生成

22. OOO / 思辨实在论（Object-Oriented Ontology / Speculative Realism）

血统：

2007 年伦敦大学学院研讨会，思辨实在论（SR）= 伞形名称：
    梅亚苏《有限性之后》(2006)—— 批判"关联主义"，寻求思维之外的绝对
    哈曼《工具存在》(2002)《四方对象》(2011)—— OOO 核心
    布拉西耶《虚无解绑》(2007)—— 反人类主义，宇宙对意义漠然
    格兰特——自然哲学，谢林路线
旁支：莫顿《超级对象》《黑暗生态学》—— 生态 OOO

核心概念：

  • 关联主义批判（梅亚苏）：哲学把存在化为"存在与思维的关系"——这是现代哲学的囚笼
  • 撤退（withdrawal）（哈曼）：对象永远有无法被任何关系穷尽的内在维度
  • 平坦本体论：去除人类特权，锤子、算法、神话本体论地位平等
  • 超级对象（hyperobject）（莫顿）：气候变化、互联网——巨大分散、超越感知尺度

与其他系关系：

  • 明确批判现象学（关联主义批判）
  • 与新物质主义核心对立：新物质主义关系先于实体，OOO 对象先于关系
  • 与 ANT：都给非人类权利，但 ANT 关系主义，OOO 实体主义
  • 哈曼《艺术与对象》(2020)：艺术是接触对象"撤退维度"的唯一方式

AI 创作节点：模型内部的生成过程对作者永远"撤退"——AI 影像有自己的 OOO 意涵

Stanley Cavell — 分析与大陆之间的焊接点

Cavell 是分析哲学内部最接近大陆传统的人，也是认知主义之外另一条分析哲学进入电影的路线： - 《所见之世界》(1971)：摄影的"自动性"（automatism）——机械印迹使影像与被摄物建立不同于绘画的本体论关系 - 呼应巴赞：两人都主张摄影有特殊的"现实性关系" - 工具不同：巴赞用现象学语言；Cavell 用维特根斯坦日常语言哲学 - 好莱坞再婚喜剧 / 女性情节剧：从日常对话的语言分析发现哲学问题（极不分析传统的研究对象） - 维特根斯坦线索：语言游戏的限制 = 表达的限制；什么是无法言说的？→ 电影能说语言无法说的吗？

与其他系的关系：

关系内容
vs 精神分析（最核心对立）Carroll《谜惑电影》直接点名：精神分析电影理论无法证伪、依赖隐喻代替论证，是"神秘化"（mystification）。认知主义用可检验命题取代无意识假设

  2. 意义先于符号还是由符号产生？ → 先于=现象学/图像学；由符号=符号学/批判理论
  3. 主体还在不在？ → 在=现象学/4E认知；消解=德勒兹的空间理论/情动/OOO；重构=后人类/后殖民
  4. 技术是工具、中介还是本体？ → 工具=普通美学；中介=技术哲学；本体=媒介理论/基特勒；加速力量=加速主义
  5. 有政治吗？有殖民性批判吗？ → 内在=批判理论/文化研究；殖民性=后殖民/解殖民/生命政治；外加=现象学；无=符号学/OOO
  6. 谈时间还是谈空间？ → 时间=叙事学/德勒兹的空间理论/技术哲学（记忆）；空间=空间理论/球域学/图像学/媒介考古
  7. 个体还是系统还是网络？ → 个体=现象学/4E；系统=系统论/媒介理论/卢曼；网络=ANT
  8. 人类中心还是后人类？ → 人类中心=现象学/认知；后人类=新物质主义/后人类主义；对象/非人类=OOO/ANT
  9. 历史的还是共时的？ → 历史=解释学/批判理论/媒介考古/后殖民；共时=符号学/系统论
  10. 能被证伪吗？ → 愿意证伪=4E认知/叙事学；不关心=现象学/德勒兹的空间理论；反对证伪=解释学
  11. 谁被赋予存在论地位？ → 主体=现象学；对象=OOO（撤退）；行动素（人+非人）=ANT；生命=生命政治；赛博格=后人类
  12. 关系先还是实体先？ → 关系先=ANT/新物质主义/装置理论；实体先=OOO/思辨实在论；都有=德勒兹的空间理论（差异化关系）
  13. 身份是本质还是生成？ → 本质=身份政治早期；生成=表演性理论（巴特勒）/德勒兹的空间理论（生成）/后人类
  14. 叙述者/分析者站在哪里？ → 西方/普世视角=传统现象学/符号学；站在被他者化者=后殖民；工具中立=系统论/ANT（但受批判）

核心判断（二十七系版）
AI 动画短片同时激活了以下理论坐标的最密集交叉：
- 图像学 + OOO：AI 影像有超出意图的自主性，"撤退"维度是美学资源
- 技术哲学 + ANT：不是"人用工具"，而是人—AI—算法—数据的异质网络共同生成
- 新物质主义 + 后人类主义：影像的物质性（噪点/幻觉/幻觉）和作者的后人类属性
- 装置理论 + 生命政治：AI 平台=当代装置，哪些身体被生成？哪些被驱逐？
- 后殖民理论：AI 训练数据的殖民性是这种创作形式无法回避的伦理坐标

这五重交叉构成一种理论密度极高的创作形式——每一个生成的帧都是理论战场。

一、垂直架构模型 (The 3-Tier Stack)

每个地方体系的位置有所不同，用下面的模型来对模型进行解释和分类

Level 1: 第一哲学与底层本体论 (Ontological Foundation)

核心提问：世界的基本构成是什么？意义的起源在哪里？

  • 主体感知本体论 (Subject-Perception)：
  • 代表：现象学。
  • 基底：肉身感知的意向性是意义的绝对起点。
  • 结构差异本体论 (Structural-Difference)：
  • 代表：符号学、叙事学、结构主义。
  • 基底：意义仅存在于形式化的系统差异中，不存在预设实体。
  • 内在性流变本体论 (Immanence-Becoming)：
  • 代表：德勒兹的空间理论主义、情动理论。
  • 基底：废除先验主体，确立物质与强度的差异化生成。
  • 对象撤退本体论 (Withdrawal-Realism)：
  • 代表：OOO、思辨实在论。
  • 基底：客体独立于任何感知或关系，具有无法被穷尽的撤退内核。

Level 2: 认识论与方法论路径 (Epistemological Path)

核心提问：我们如何获取知识？逻辑运作的路径是什么？

  • 谱系学与考古学 (Genealogy/Archaeology)：拒绝目的论，寻找历史的断裂与话语的形成规律（如媒介考古学）。
  • 拓扑网络追踪 (Network Tracking)：拒绝预设宏观结构，追踪人类与非人类实体的实时纠缠（如 ANT）。
  • 症状阅读与揭露 (Symptomatic Reading)：穿透影像表象，定位被压抑的无意识或意识形态（如精神分析、批判理论）。
  • 现象学还原 (Phenomenological Reduction)：悬置判断，回归“事物本身”的直接显现。

Level 3: 区域研究与应用透镜 (Regional Lenses)

核心提问：针对具体客体（影像、身体、空间）的操作策略。

  • 空间/共居维度：球域学、空间理论。
  • 权力/主体化维度：生命政治、身份政治、后殖民理论。
  • 界面/物质维度：媒介理论、后人类主义、新物质主义。

二、核心重构原则

  1. 强制性声明 (Mandatory Declaration)：
  2. 当讨论“后人类主义”时，必须明确：你是站在“德勒兹的空间理论式的生成本体论”基础上的，还是站在“OOO 的对象本体论”基础上的？这两者导致的后人类影像分析截然不同。
  1. 认识论断裂标记 (Epistemological Rupture)：
  2. 在地图中，必须用明确的物理边界划分“主体中心理论”（现象学、4 E）与“去中心化理论”（德勒兹的空间理论、ANT、OOO）。禁止在不说明兼容逻辑的情况下跨界提取工具。
  1. 处理复合概念（以装置理论为例）：
  2. 装置（Apparatus/拉康系）：应锚定在“结构差异本体论”+“症状阅读认识论”下。
  3. 装置（Dispositif/福柯系）：应锚定在“内在性平面”+“谱系学认识论”下。
  4. 通过这种分层，可以彻底解决术语混淆问题。

三、判定法升级：五重深度问询

遇到任何理论文本，依次问询：

  1. 第一哲学基底：它承认先验主体吗？
  2. 形而上逻辑：它认为关系先于实体，还是实体先于关系？
  3. 认识论路径：它是通过“揭露症状”还是“追踪网络”来建立论据的？
  4. 本体论承诺：它赋予非人类对象（如 AI 算法）独立的存在地位吗？
  5. 目的论指向：它是在进行政治解殖，还是在进行纯粹的感知还原？
